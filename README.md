Описание тестов:

1. Тесты для add_new_book
Проверяют добавление книги с валидным названием, невозможность добавления книги с пустым названием или слишком длинным (>40 символов).
Проверяют, что дубликаты книг не добавляются.

2. Тесты для set_book_genre
Проверяют установку валидного жанра для книги, невозможность установки несуществующего жанра, а также  что жанр не устанавливается для несуществующей книги.

3. Тесты для get_book_genre
Проверяют, что для новой книги жанр не установлен (возвращает пустую строку).

4. Тесты для get_books_with_specific_genre
Проверяют фильтрацию книг по жанру и что для несуществующего жанра возвращается пустой список.

5. Тесты для get_books_genre
Проверяют, что метод возвращает корректный словарь книг и их жанров.

6. Тесты для get_books_for_children
Проверяют, что книги с жанрами "Ужасы" и "Детективы" не попадают в список для детей и что книги с "безопасными" жанрами ("Фантастика", "Мультфильмы", "Комедии") возвращаются.

7. Тесты для add_book_in_favorites
Проверяют добавление книги в избранное и невозможность добавления дубликатов в избранное.
Проверяют, что нельзя добавить несуществующую книгу.

8. Тесты для delete_book_from_favorites
Проверяют удаление книги из избранного.

9. Тесты для get_list_of_favorites_books
Проверяют, что избранные книги возвращаются корректно и что для пустого списка избранного возвращается пустой список.
